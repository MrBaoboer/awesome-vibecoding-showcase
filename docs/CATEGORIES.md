# 项目分类

[英文版](CATEGORIES.en.md)

本文件供维护者归类。提交者只需描述产品，不需要判断最终分类。收录资格以[收录标准](CRITERIA.md)为准。

## 一级分类

每个项目只使用一个一级分类和该分类下的一个二级分类。

| 一级分类 | 适用范围 |
| --- | --- |
| `productivity-collaboration`｜生产力与协作 | 通用的任务组织、沟通协作和个人工作流 |
| `business-operations`｜商业与运营 | 销售、交易、财务、行政和客户支持等经营流程 |
| `education-knowledge`｜教育与知识 | 学习、教学、研究、参考和知识沉淀 |
| `data-decision`｜数据与决策 | 将数据转化为分析、预测、计划或选择 |
| `creative-media`｜创意与媒体 | 文字、视觉、音频和视频的创作、编辑或发布 |
| `health-lifestyle`｜健康与生活 | 个人健康、家庭、日常生活、旅行和本地体验 |
| `community-public-good`｜社区与公共利益 | 公共服务、无障碍、社区协作和公益行动 |
| `games-entertainment`｜游戏与娱乐 | 游戏循环、互动娱乐、社交消遣和兴趣活动 |

## 归类规则

1. 按产品核心流程带来的主要结果分类，不按技术栈、AI 工具或宣传主题分类。
2. 面向明确经营职能的流程归入“商业与运营”；通用工作管理归入“生产力与协作”。
3. 主要结果是理解或技能提升时归入“教育与知识”；主要结果是消遣时归入“游戏与娱乐”。
4. 主要结果是分析、预测或方案取舍时归入“数据与决策”；数据只用于执行经营流程时归入“商业与运营”。
5. 主要结果是产出媒体内容时归入“创意与媒体”；成品本身是互动游戏时归入“游戏与娱乐”。
6. 主要服务个人或家庭生活时归入“健康与生活”；公共受益是首要目标时归入“社区与公共利益”。
7. 多个分类均适用时，依次比较公开定位、核心流程、首页首项已上线功能，选择范围更具体的一项，并在审核 Issue 中记录理由。

## 排序

分类内按 `added_on` 倒序排列；同日按项目 `id` 的 ASCII 升序排列。更新项目不改变首次收录日期。
