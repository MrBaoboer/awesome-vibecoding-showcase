## 5. 决定规则

- **`status: approved`：** 范围预检通过，C1–C5 全部通过，D1–D5 完整，分类有效。
- **`status: needs-info`：** 没有明确反证，但存在可合理补充的证据或字段缺口。应一次性列出所有缺口。
- **`status: declined`：** 任一强制标准明确不满足、属于排除范围，或补充后仍不能公开核验。
- **`status: removed`：** 已收录项目不再满足任一 C 条件；记录首次失败日期、复核结果和下架理由。

不得以“其余四项很好”为由豁免任何一项 C 标准。
