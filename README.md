## 提交新项目

提交前，请确认项目同时满足：

- 有可公开访问的产品或演示；
- 有包含主体实现的公开源码仓库；
- AI 通过自然语言协作完成了大部分核心功能代码；
- 核心流程可运行，并有完成度、实用性或创新性的具体依据；
- 产品、源码、说明和开发证据真实且相互一致。

提交步骤：

1. 搜索橱窗和现有 Issue，避免重复提交。
2. [打开项目提交表单](https://github.com/MrBaoboer/Awesome-VibeCoding-Showcase/issues/new?template=project-submission.yml)，填写产品解决的问题、功能与价值、技术栈、AI 开发方式、在线体验和源码地址。

一个 Issue 只提交一个项目。无需选择分类或先创建 Pull Request；维护者会在 Issue 中完成初审、确定分类并整理条目。

详细判定和分类规则见[收录标准](docs/CRITERIA.md)与[项目分类](docs/CATEGORIES.md)。
