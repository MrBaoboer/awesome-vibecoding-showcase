# Assets policy

Only assets directly supporting an admitted project or repository documentation belong here.

- Prefer WebP, 16:9, at most 300 KB per project screenshot.
- Provide meaningful alt text in both README outputs.
- Do not store private AI conversations, secrets, personal data, or copyrighted assets without permission.
- Screenshots supplement C1; they never replace a working public experience.
- Contributors retain responsibility for permissions and attribution. Record third-party notices in `NOTICE`.
